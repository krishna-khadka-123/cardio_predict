## Features

- Interactive patient input interface
- Cardiovascular disease risk prediction
- Logistic Regression model
- StandardScaler preprocessing
- Probability-based prediction
- Confusion matrix
- Classification report
- Precision, Recall, and F1-score
- Model accuracy visualization
- Streamlit web interface

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression

## Machine Learning

The prediction pipeline uses:

- StandardScaler
- Logistic Regression
- Balanced class weights
- Train/test split
- Classification report
- Confusion matrix

The model uses patient information such as:

- Age
- Gender
- Height
- Weight
- Systolic blood pressure
- Diastolic blood pressure
- Cholesterol
- Glucose
- Smoking
- Alcohol consumption
- Physical activity

## Model Performance

The model achieved approximately **74.3% accuracy** on the test dataset.

## Disclaimer

This project is for educational and demonstration purposes only.
It is not a medical diagnostic tool and should not be used for medical decisions.
